Get started

Running in a few minutes

You need Python 3.10 or newer and a folder of files you want to share. Nothing else has to be installed.

  1. Download the latest release and extract it.

    Any folder will do. Your settings are kept in conf/ and your data in data/, and an upgrade never changes either.

  2. Run the launcher for your system. 
    scripts\windows\start-dccore.bat        (Windows: double-click it)
scripts/linux/start-dccore.sh           (Linux)
scripts/macos/start-dccore.command      (macOS)

    On Windows, if Python is missing, the launcher offers to install it for you.

  3. Answer the setup questions.

    The first run asks for the bot's name, the server, its channels, your own nick as its admin and the folder you share. It can ask in the terminal or on a setup page in your browser.

  4. Build the first list. 
    python3 update_list.py        (Windows: py update_list.py)

    On a large library this takes a while. The bot keeps answering while it runs.

Before you open it to the world

  • Check firststart-dccore check tests your settings without going online.
  • Open the DCC portsFiles go out on a small range of ports. Allow it in your firewall and forward it in your router. The check prints your range.
  • Start with the systemOne script installs it: a user service on Linux, a launch agent on macOS, a task at logon on Windows.
  • Hear about updatesOnce a day the bot asks GitHub whether a new release is out, and says so in the dashboard, the console and the mIRC window.
  • UpgradingStop the bot, back up data/ and conf/, and extract the new release. An upgrade never changes your settings or statistics.
