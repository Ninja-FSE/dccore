Update list

Rebuilds the master list by walking the whole music directory again — the same rebuild !update triggers over IRC. Worth running here right after setting or changing the music directory from the Settings page, since nothing else prompts for it automatically.

Verify list

Reads the master list and reports any filename that appears under more than one folder. A request that names a file alone reaches only the first copy listed under that name — the rest are shadowed by it. Pasting a search result’s whole line, size included, reaches the copy that size names.
